
Bem-vindo ao repositório ArrayCollection! Este projeto é uma solução em Java para gerenciar e manipular coleções de dados de maneira eficiente e flexível, para materia de Programação Orientada a Objetos em Java
O ArrayCollection é serie de soluções de exercicios da faculdade com arrays e coleções em Java. Com métodos para filtragem, mapeamento, ordenação e agregação, esta biblioteca é ideal para desenvolvedores que precisam de ferramentas adicionais para manipulação de dados.
